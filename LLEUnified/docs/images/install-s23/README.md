# S23 installation screenshots

These 23 images document the tested Samsung first-start sequence used by
[`INSTALL_APK.md`](../../INSTALL_APK.md).

They currently show the co-installable **L.L.E Tester** package and are a draft
reference set. Before publishing the final stable guide, replace them with
captures of the signed **L.L.E 64** package while preserving the filenames and
order.

The sequence covers:

1. Play Protect scan and warning.
2. The first blocked Accessibility attempt.
3. L.L.E's restricted-settings recovery page.
4. **App info → three-dot menu → Allow restricted settings**.
5. The second Accessibility attempt and system confirmation.
6. Battery, wallpaper, feature, capture, and touch-box wizard pages.
7. Setup completion and the main screen.

When replacing images, remove personal information and keep the portrait
orientation, display scale, and English UI consistent.
